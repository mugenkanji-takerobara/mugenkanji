きぼうかんじ　GitHub公開手順

==================================================
最初に行うこと
==================================================

1. このZIPを「すべて展開」します。

2. 展開したフォルダの中にある
   01_素材を取り込む.bat
   をダブルクリックします。

3. フォルダを選ぶ画面が開いたら、
   現在正常に動作している
   KIBOUKANJI_VER1_TEST
   を選びます。

4. 次に
   02_公開前チェック.bat
   をダブルクリックします。

5.
   必要なファイルはすべてそろっています。
   GitHubへアップロードできます。
   と表示されれば準備完了です。

==================================================
GitHubの画面からアップロードする方法
==================================================

1. GitHubで公開するリポジトリを開きます。

2. リポジトリの一番上にindex.htmlが置かれるようにします。
   ZIPファイルそのものをアップロードするのではありません。
   展開したフォルダの「中身」をアップロードします。

3. Add fileからUpload filesを選びます。

4. 展開したフォルダの中身をすべて選び、
   GitHubの画面へドラッグします。

5. Commit changesの入力欄へ、例えば次のように入力します。

   Release KIBOUKANJI Ver.1.0.0

6. Commit changesを押します。

==================================================
GitHub Pagesを有効にする
==================================================

1. リポジトリのSettingsを開きます。

2. Pagesを開きます。

3. 公開元として、公開版ファイルを置いたブランチと
   リポジトリのルートフォルダを選びます。

4. 保存後、公開アドレスが表示されるまで少し待ちます。

5. 公開アドレスをスマートフォンで開きます。

==================================================
公開後に確認すること
==================================================

・TOP画像が全部表示される
・パズル、使いかた、とやまの3ボタンが表示される
・通常BGMが流れる
・5種類の効果音が短く鳴る
・富山城背景が切り替わる
・特の符を使う、ためておくが動く
・使いかたの画像がすべて表示される
・とやまの写真が表示される
・雨晴海岸物語の画像と音が表示される
・続編予告動画が映像と音声付きで再生される
