# きぼうかんじ

## とやまの無限漢字  
### ～立山連峰から富山湾まで　希望の数え唄～

富山の景色と漢字を楽しむ、スマートフォン向け落ち物パズルゲームです。

## 公開版

- バージョン：1.0.3
- 対応：スマートフォン・PCブラウザ
- 操作：スワイプ／ドラッグ
- インストール：不要
- スコア：端末内へTOP3を保存

## 主な内容

- 同じ漢字を縦または横に三つそろえて消去
- 急降下した高さに応じて10～90点を加算
- 100点ごとに富山城の背景が変化
- 「代」「岳」の特別な力を持つ「特の符」
- 特の符は「使う」「ためておく」から選択
- 富山県観光地案内
- 雨晴海岸きぼうかんじ伝説
- 続編「未来の雨晴海岸」予告動画
- 日本語の使いかた

## ファイル構成

```text
index.html            ゲーム本体と各画面
manual.html           使いかた
game-core.js          初期化・ゲームループ
game-board.js         盤面・得点・特の符
game-draw.js          描画・背景・ランキング
game-audio.js         BGM・効果音
game-ui.js            画面操作
future_teaser.mp4      続編予告動画
```

## 公開前の準備

このパッケージを展開した直後は、写真・物語画像の一部を
現在動作している確認用フォルダから取り込む必要があります。

1. `01_素材を取り込む.bat`をダブルクリック  
2. `KIBOUKANJI_VER1_TEST`フォルダを選択  
3. `02_公開前チェック.bat`をダブルクリック  
4. 「必要なファイルはすべてそろっています」と表示されたら準備完了  

## ローカル確認

`03_スマートフォン確認を開始.bat`をダブルクリックします。

PCでは次を開きます。

```text
http://localhost:8000/?v=1.0.3
```

スマートフォンでは、黒い画面に表示されたIPアドレスを使います。
