# KIBOUKANJI — Ver.1.0.12

GitHub Pages 公開専用パッケージ。

- 公開中 Ver.1.0.9 の更新用ファイルを基準に、実機合格した Ver.1.0.12 の内容を統合。
- Ver.1.0.11 の WebP / オフライン PWA 実験版は不採用。
- Service Worker は使用しない。
- `index.html` を含むこのフォルダーの中身を GitHub Pages 公開元の最上位へ配置する。
- ローカル起動 BAT / PowerShell / テスト用 HTML は公開フォルダーに含めない。

## 公開後の最小確認

1. PC と iPhone Safari でトップページが開く。
2. HTTPS 上で「ランキング画像をコピー」を確認する。
3. コピー成功時だけ成功表示され、失敗時に自動ダウンロードされないことを確認する。
