# KIBOUKANJI Ver.1.0.8

スマートフォンのブラウザで遊べる、富山の景色と漢字を組み合わせた落ち物パズルです。

## Ver.1.0.8 の主な更新

- 富山城背景を春4枚・夏8枚・秋5枚・冬3枚の合計20ファイルへ更新
- 前回と異なる季節から始まり、春夏秋冬の流れを保ちながら季節内を毎回ランダム表示
- 20ファイルを一巡するまで同じファイル名を重複表示しない方式へ変更
- 背景写真を先読みし、約650ミリ秒で滑らかに切り替える処理を追加
- URLを貼るだけでタイトル・説明・紹介画像が出やすくなるOGP情報を追加
- 操作対象の名称を「漢字錠（カンジジョウ）」へ統一
- GLYPH（グリフ）を漢字錠に宿る漢字エネルギーとして説明書へ追加
- 説明書1ページ目を、漢字錠とGLYPHの世界観・操作・消去説明へ再構成
- コンボ演出へ「連続開花」「連綿たる調和」「重々無尽の波紋」を追加
- 「代」にタイシンセングウ（代身遷宮）、「岳」にサンガクチンテイ（山岳鎮定）の演出を追加
- ランキング上部を画像としてコピー・保存できる機能を追加
- ランキングの日本語説明を読みやすく再配置
- 「特の符」の二重実行、同じ漢字錠の二重選択、確認前の実行を防ぐ安全処理を強化
- 説明書画像の一時的な読み込み失敗時に再試行する処理を追加

## 背景写真について

登録は20ファイルです。ただし、提供された `toyama-castle-autumn-03.jpg` と `toyama-castle-autumn-05.jpg` は内容が同一です。そのため、現時点では20ファイル・実質19種類の写真です。ゲームでは提供時のファイル名をそのまま登録しています。
